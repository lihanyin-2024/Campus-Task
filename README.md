# 课业待办 · CampusTask

面向校园场景的**任务管理 Web 应用**，使用原生 **HTML + CSS + JavaScript** 实现，无需安装任何依赖，双击 `index.html` 即可在浏览器中运行。

## 运行方式

1. 直接用浏览器（推荐 Chrome / Edge）打开 `index.html`。
2. 或在本目录启动任意静态服务器，例如 `python -m http.server 8080`，访问 `http://localhost:8080`。

## 功能一览

| 模块 | 功能 |
| --- | --- |
| 任务管理 | 表格清单，增删改查、标记完成、分类/优先级/标签/截止时间/预计耗时/后果严重 |
| 预设视图 | 全部 / 今天截止 / 本周截止 / 已逾期 / 重要 / 已完成 / 未完成 一键切换 |
| 批量管理 | 批量勾选、批量完成/删除，一键清除已完成 |
| 本地持久化 | localStorage 自动保存（含数据校验与迁移） |
| 番茄钟 | 自定义专注时长，基于时间戳精确计时，提示音与桌面通知 |
| 未来 7 天时间表 | 课程(蓝)/空闲(灰)/计划任务(紫)/固定休息(橙)/课程缓冲(灰虚线)统一排进周历 |
| 空闲块编辑 | 点击「空闲」色块，可调整起止时间、编辑备注或从任务列表填入该时段 |
| 固定休息 | 自由设置「吃饭 / 午睡 / 晚睡」时段，休息时间不安排任何工作 |
| 手动排课 | 点击时间表「空闲」色块，从任务列表填入该时段（自动避开课程 30 分钟缓冲） |
| 每日一言 | 每天固定一条，次日更新（fetch 加载 + 本地降级） |
| 明暗主题 / 响应式 | CSS 变量双主题，移动端抽屉导航 |

## 目录结构

```
大作业/
├── index.html          # 页面入口
├── css/style.css       # 全部样式（双主题、响应式、时间表）
├── data/quotes.json    # 每日一言数据（fetch 演示）
├── js/
│   ├── utils.js        # 命名空间与工具函数
│   ├── storage.js      # 数据持久化层（localStorage + 校验/迁移）
│   ├── model.js        # 任务模型、预设视图、周历与计划算法
│   ├── pomodoro.js     # 番茄钟
│   ├── router.js       # 哈希路由（SPA）
│   ├── view.js         # 视图层（表格、批量、时间表、计划）
│   └── app.js          # 入口（初始化、时钟、提醒、示例数据）
└── README.md
```
