    休息时间不安排任何工作；空闲时间由系统自动计算（课程、任务、休息之外的时间）。

      关于本项目

      基于原生 HTML / CSS / JavaScript 的校园任务管理 SPA 应用。

      使用说明

      1. 运行：双击 index.html，或执行 python -m http.server 8080 后访问对应地址。
      2. 添加任务：点击右下角「＋」或按 N 键。
      3. 完成/编辑/删除：在清单页对应行操作。
      4. 快速查看：左侧「视图」一键切换今天截止 / 本周截止 / 已逾期 / 已完成等。
      5. 批量管理：点「批量管理」勾选后批量完成或删除；「清除已完成」一键清理。
      6. 手动排课：在「计划」页录入课程表与固定休息（吃饭/午睡/晚睡），空闲时间自动计算；点击时间表里的「空闲」色块，从任务列表填入该时段（自动避开课程 30 分钟缓冲）。
      7. 空闲块编辑：点击时间表中的「空闲」色块，可添加备注或从任务列表填入该时段。
      8. 番茄钟：在「专注」页可自定义专注时长。
